# Разделение типа агентов

Сейчас у [Agent](src/use_cases/agent.rs) есть только один конструктор, который создает агента.

## Задача

Сделать вместо одного конструктора new три, которые будут создавать Agent с разным набором tools:

1. `new_subagent`. Это будет агент-исполнитель. Вот его доступные tools:

- `create_directory`
- `create_file`
- `delete_path`
- `fetch_url`
- `find_paths`
- `list_directory`
- `read_file`
- `rename_path`
- `run_command`
- `fetch_url`

2. `new_orchestrator_agent`. Это будет агент-оркестратор. Вот его доступные tools:

- `create_directory`
- `create_file`
- `fetch_url`
- `find_paths`
- `list_directory`
- `read_file`
- `run_command`
- `fetch_url`

2. `new_chat_agent` (полный набор tools, то что сейчас делает конструктор `new`). Это агент для чата

- `apply_patch`
- `create_directory`
- `create_file`
- `delete_path`
- `fetch_url`
- `find_paths`
- `list_directory`
- `read_file`
- `rename_path`
- `run_command`
- `fetch_url`

Итого должно быть создано 3 конструктора, третий конструктор должен использоваться, а первые два - пока что нет.
